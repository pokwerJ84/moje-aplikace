GYM TRACKER PRO – GITHUB PAGES

1. Nahraj všechny soubory z této složky do GitHub repozitáře.
2. V GitHubu otevři Settings → Pages.
3. Source nastav na Deploy from a branch.
4. Vyber branch main a složku /root.
5. Počkej na zveřejnění adresy.

INSTALACE DO TELEFONU
iPhone: otevři GitHub Pages adresu v Safari → Sdílet → Přidat na plochu.
Android: otevři v Chrome → menu → Přidat na plochu / Instalovat aplikaci.

DŮLEŽITÉ
- Data se ukládají lokálně v konkrétním prohlížeči.
- Jednou týdně použij Export zálohy.
- QR a video odkazy potřebují internet.
- Offline fungování začne až po prvním otevření přes GitHub Pages.
